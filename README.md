# OMR স্ক্যানার (PWA + Google Apps Script + GitHub Pages)

ফোনে ইনস্টল করা যায় এমন OMR মূল্যায়ন অ্যাপ। ছবি তুললেই খাতা স্ক্যান হয়, দাগের ওপর হালকা বৃত্ত আসে, ভুল শনাক্ত হলে পরীক্ষক নিজে ঠিক করতে পারেন, সাবমিট করলে সঠিক/ভুল/প্রাপ্ত নম্বর আসে।

## ফিচার
- ১০০ প্রশ্নের OMR শিট (৪টি অপশন: ক খ গ ঘ)। ১–১০০ এর মধ্যে যত খুশি প্রশ্নের উত্তর সেট করে নাম দিয়ে সংরক্ষণ (একাধিক উত্তরমালা রাখা যায়)
- খাতার ছবি → কোণার ৪টি কালো বর্গ দিয়ে ছবি সোজা করা (পারস্পেক্টিভ সংশোধন) → দাগ শনাক্ত → হালকা নীল বৃত্ত
- বৃত্ত না এলে/ভুল এলে ট্যাপ করে ম্যানুয়ালি যোগ বা মোছা (ম্যানুয়াল বৃত্ত ড্যাশ-বর্ডারে দেখায়)
- সাবমিটে: সঠিক, ভুল, উত্তর-না-দেওয়া, কর্তন, প্রাপ্ত নম্বর। সঠিক = সবুজ, ভুল = লাল, সঠিক উত্তর = সবুজ ড্যাশ রিং
- প্রতি ভুলে −০.২৫ (পরিবর্তনযোগ্য), “সেকেন্ড টাইমার” বোতামে মোট নম্বরের ৩% (পরিবর্তনযোগ্য, ৫% ইত্যাদি)
- অ্যাডমিন পিন দিয়ে সেটিং/উত্তরমালা সুরক্ষা; ফলাফলের তালিকা + CSV ডাউনলোড
- ইনস্টলযোগ্য PWA, অফলাইনেও চলে (সার্ভার সিঙ্ক ঐচ্ছিক)
- Apps Script + Google Sheet এ ক্লাউড সংরক্ষণ, একাধিক ফোন থেকে একই উত্তরমালা ও ফলাফল

## ফাইল
| ফাইল | কাজ |
|---|---|
| `index.html` | UI |
| `app.js` | শিট আঁকা, উত্তরমালা, ফলাফল গণনা, সিঙ্ক |
| `omr-core.js` | ছবি থেকে দাগ শনাক্তের লজিক (মার্কার খোঁজা, হোমোগ্রাফি, নমুনা নেওয়া) |
| `sw.js`, `manifest.json`, `icon-*.png` | ইনস্টল ও অফলাইন (PWA) |
| `Code.gs` | Google Apps Script ব্যাকএন্ড |

## ধাপে ধাপে চালু করা

### ১. GitHub Pages এ হোস্ট
1. github.com এ নতুন public repository খুলুন (যেমন `omr-app`)।
2. `Code.gs` ও `README.md` সহ সব ফাইল আপলোড করুন (Add file → Upload files)।
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder: `/ (root)` → Save।
4. ১–২ মিনিট পর `https://<ইউজারনেম>.github.io/omr-app/` এ অ্যাপ পাবেন।

### ২. Apps Script ব্যাকএন্ড (ঐচ্ছিক, কিন্তু একাধিক ডিভাইসের জন্য দরকারি)
1. নতুন Google Sheet খুলুন → Extensions → Apps Script।
2. `Code.gs` এর পুরো কোড পেস্ট করে সেভ করুন।
3. Project Settings (⚙) → Script properties → `ADMIN_PIN` নামে একটি প্রপার্টি যোগ করে নিজের পিন দিন।
4. Deploy → New deployment → Type: **Web app** → Execute as: **Me** → Who has access: **Anyone** → Deploy। অনুমতি দিন।
5. যে `.../exec` URL পাবেন সেটি কপি করুন।
6. অ্যাপে সেটিং ট্যাবে: অ্যাডমিন পিন (শুরুতে `1234`), Web App URL বসান, **নতুন পিন** ঘরে একই ADMIN_PIN দিন, সংরক্ষণ করুন।
7. কোড বদলালে Deploy → Manage deployments → Edit → New version দিয়ে আবার ডিপ্লয় করতে হবে।

### ৩. ফোনে ইনস্টল
- Android Chrome: অ্যাপের “ইনস্টল” বোতাম, না এলে মেনু (⋮) → Install app / Add to Home screen।
- iPhone: Safari → Share → Add to Home Screen।

## ব্যবহারের নিয়ম
1. **উত্তরমালা ট্যাব:** শিটে সঠিক উত্তরে ট্যাপ করুন → নাম দিন → সংরক্ষণ।
2. **“খালি OMR শিট” বোতামে** PNG নামিয়ে A4 এ ১০০% মাপে প্রিন্ট করুন। পরীক্ষার্থী **এই শিটেই** দাগ দেবে। (শিটের বৃত্ত ও কোণার কালো বর্গের অবস্থানের ওপর স্ক্যান নির্ভর করে, অন্য ডিজাইনের খাতা চলবে না।)
3. **স্ক্যান ট্যাব:** উত্তরমালা বাছুন, নাম/রোল লিখুন, ছবি তুলুন। বৃত্ত ঠিক করুন → সাবমিট।
4. **ফলাফল ট্যাব:** সব ফলাফল, CSV এক্সপোর্ট।
5. **সেটিং ট্যাব (পিন লাগবে):** প্রতি সঠিকের নম্বর, ভুলের কর্তন, টাইমার %, শনাক্তের সীমা।

নম্বরের হিসাব: `প্রাপ্ত = সঠিক × নম্বর − ভুল × কর্তন − (টাইমার চালু থাকলে মোট × %)`, নিচে ০ এর কম হয় না। একাধিক বৃত্তে দাগ = ভুল। ফাঁকা = কর্তন নেই। শুধু উত্তরমালায় সেট করা প্রশ্নগুলো গণনায় আসে।

## ভালো স্ক্যানের টিপস
- চারটি কোণার কালো বর্গ পুরোপুরি দেখা যেতে হবে, কোনোটি আঙুল/ছায়ায় ঢাকা নয়
- খাতা সমতল টেবিলে রেখে, সমান আলোয়, মোটামুটি ওপর থেকে ছবি তুলুন
- ছবি খাড়া (portrait) রাখুন। উল্টো/আড়াআড়ি হলে “↻ ঘোরান” চাপুন
- পরীক্ষার্থী বৃত্ত গাঢ়ভাবে ভরাট করবে (কালো কলম/গাঢ় পেন্সিল)
- হালকা দাগ ধরা না পড়লে সেটিংয়ে “শনাক্তের সীমা” কমান (যেমন ০.১৫); ভুল দাগ ধরলে বাড়ান (যেমন ০.২৫)

## কীভাবে কাজ করে
1. ছবি ≤১৪০০px এ ছোট করা → অ্যাডাপটিভ থ্রেশহোল্ড → কালো বর্গাকার ব্লব খুঁজে ৪ কোণ নির্ধারণ
2. ৪ কোণ থেকে পারস্পেক্টিভ ম্যাট্রিক্স বের করে ছবিকে ১০০০×১৪৫০ শিটের মাপে সোজা করা
3. প্রতিটি বৃত্তের ভেতরের গড় উজ্জ্বলতা আশপাশের কাগজের উজ্জ্বলতার সাথে তুলনা করে “কালিমা” মাপা (ছায়ায় সমস্যা কম হয়)
4. সীমার বেশি কালিমা = দাগ; একটি প্রশ্নে অনেক বৃত্ত গাঢ় হলে একাধিক দাগ

## রোডম্যাপ
**ধাপ ১ (এই ভার্সন):** শিট, উত্তরমালা, স্ক্যান, ম্যানুয়াল সংশোধন, ফলাফল, PWA, Sheet সিঙ্ক
**ধাপ ২ — বাস্তব পরীক্ষা (১–২ সপ্তাহ):** আসল প্রিন্ট করা শিটে ৩০–৫০টি খাতা স্ক্যান করে সীমা (`thr`) ক্যালিব্রেট করা; ভিন্ন ফোন/আলোয় পরীক্ষা
**ধাপ ৩ — উন্নয়ন:** রোল/সেট কোড বৃত্ত (বার্ষিক রোল স্বয়ংক্রিয়), A/B/C/D সেট, প্রশ্নভিত্তিক নম্বর, প্রতি প্রশ্নের একাধিক সঠিক উত্তর
**ধাপ ৪ — পেশাদার ফিচার:** ব্যাচ স্ক্যান, মেধাতালিকা ও পরিসংখ্যান, PDF রিপোর্ট, কঠিন প্রশ্ন বিশ্লেষণ, স্কুল/কোচিং ভিত্তিক ব্যবহারকারী লগইন
**ধাপ ৫ — নিরাপত্তা:** পিন সার্ভারে হ্যাশ করা, Apps Script এ ইউজার ভিত্তিক অনুমতি (বা Firebase), অডিট লগ

## সীমাবদ্ধতা (সৎভাবে)
- অ্যাডমিন পিন হালকা সুরক্ষা মাত্র (ব্রাউজারে সংরক্ষিত)। কঠোর নিরাপত্তা লাগলে ধাপ ৫ দেখুন
- Apps Script “Anyone” অ্যাক্সেসে URL জানা থাকলে ফলাফল জমা দেওয়া যায়। URL গোপন রাখুন
- ছবির মান খারাপ হলে ভুল শনাক্ত হতে পারে — তাই ম্যানুয়াল সংশোধনের সুবিধা আছে। বড় পরীক্ষায় সাবমিটের আগে বৃত্তগুলো একবার দেখে নিন
